# Internationalization

Locales: `en` (default) and `uk`. Library: next-intl 4.

## Routing

Every page lives under a locale prefix (`/en/...`, `/uk/...`, `localePrefix: "always"`).
`frontend/src/proxy.ts` runs the next-intl middleware: a request without a prefix is redirected
to the locale from the `NEXT_LOCALE` cookie, then `Accept-Language`, then `en`.
Configuration: `src/infrastructure/i18n/routing.ts`; use `Link`, `useRouter`, `usePathname` and
`redirect` from `src/infrastructure/i18n/navigation.ts`, never the `next/link` equivalents, so
the locale is preserved.

## Messages

- `frontend/src/messages/en.json`, `frontend/src/messages/uk.json`, loaded per request in
  `src/infrastructure/i18n/request.ts`.
- Namespaces: `meta`, `common`, `nav`, `accounts`, `sync`, `mail`, `reader`, `search`,
  `composer`, `auth`, `validation`, `errors`, `settings`.
- Components call `useTranslations("<namespace>")`. No user-facing string is written in a
  component; this includes `aria-label`s, toasts, validation and error messages.
- Plurals use ICU syntax; Ukrainian messages define `one`, `few`, `many`, `other`.
- Zod schemas return keys of the `validation` namespace as error messages; API errors are mapped
  by `errorKey()` to keys of the `errors` namespace.

`src/messages/messages.test.ts` fails the build when the two files differ in keys or
placeholders, when a message is empty, or when a Ukrainian message is identical to the English
one (brand and provider names are allow-listed).

## Switching language

`LanguageSwitch` (`src/shared/components/layout/preferences.tsx`) replaces the locale segment of
the current URL; next-intl stores the choice in the `NEXT_LOCALE` cookie (1 year). When signed in,
Settings → Appearance also sends `PATCH /settings { locale }` so the backend can localize the
emails it sends. The URL is the source of truth for the interface language.

## Dates and numbers

`src/shared/utils/format.ts` formats with `Intl.DateTimeFormat(locale)` in the browser's time
zone (list dates, message dates, full dates) and byte sizes.

## Adding a string

1. Add the key to **both** JSON files.
2. Use it through `useTranslations`.
3. Run `pnpm test` (parity check) and review the screen in Ukrainian at 320px — Ukrainian labels
   are routinely 30–60% longer.

## Adding a locale

Add it to `locales` in `routing.ts`, create `messages/<locale>.json`, add its name to
`LOCALE_NAMES` in `preferences.tsx`, extend the backend `Settings.locale` enum, and include the
locale in the Inter font subsets in `src/app/[locale]/layout.tsx` if it needs another script.
